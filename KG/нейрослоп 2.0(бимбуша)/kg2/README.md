# Лабораторная работа №2 — B-сплайн кривые

## Вариант 9

Сформировать на плоскости B-сплайновую кривую различной степени (1, 2, 3, 4, 5, 6)
на основе 7 не повторяющихся задающих точек. Обеспечить редактирование координат
задающих точек с перерисовкой сплайна.

### Что реализовано

- базисные функции B-сплайна по рекуррентной формуле Кокса — де Бура;
- вычисление точки кривой алгоритмом де Бура (устойчивая схема);
- произвольная степень p = 1…6 (ограничена числом задающих точек);
- зажатый (clamped) и равномерный периодический узловые векторы;
- задающее число точек 4…10 (по варианту — 7);
- редактирование координат точек полями ввода и перетаскиванием мышью;
- режим «показать все степени 1…6» с одновременной отрисовкой кривых;
- отображение задающей ломаной, задающих точек, осей, сетки и отметок узлов;
- график базисных функций N(i,p)(u) для текущей степени;
- автоматический подбор масштаба («Вписать в холст»);
- сохранение и загрузка задания в JSON;
- ортогональное проецирование на плоскость визуализации;
- запуск без OpenGL и без сторонних Python-библиотек;
- Docker + Xvfb + x11vnc + noVNC для запуска GUI через браузер.

### Формулы

Базисная функция степени p (рекуррентная формула Кокса — де Бура):

```text
N(i,0)(u) = 1, если u(i) <= u < u(i+1), иначе 0
N(i,p)(u) = (u - u(i)) / (u(i+p) - u(i)) * N(i,p-1)(u) +
            (u(i+p+1) - u) / (u(i+p+1) - u(i+1)) * N(i+1,p-1)(u)
```

Точка B-сплайна:

```text
C(u) = сумма по i от 0 до n  N(i,p)(u) * P(i)
```

Число узлов узлового вектора — n + p + 2, где n + 1 — число задающих точек.

## Принцип алгоритма

1. По числу задающих точек n + 1 и степени p строится узловой вектор длины n + p + 2
   (зажатый либо равномерный периодический).
2. Для параметра u отыскивается индекс пролёта (двоичный поиск по узлам).
3. Ненулевые базисные функции в точке вычисляются по рекуррентной формуле
   Кокса — де Бура; точка кривой — по алгоритму де Бура.
4. Параметр u пробегает область определения кривой с заданным числом точек на
   пролёт, полученные точки соединяются отрезками (линейная аппроксимация).
5. Мировые координаты отображаются на холст ортогональным проецированием с
   единым коэффициентом масштаба по обеим осям.

В режиме «все степени» пункты 1–4 выполняются для каждой степени p = 1…min(6, n),
что позволяет сравнить кривые одинакового задания при разной степени.
