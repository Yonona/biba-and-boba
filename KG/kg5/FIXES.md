# Исправления в kg5_fixed

Каталог `kg5_fixed` — копия проекта `kg5` с исправлениями, выявленными при
подготовке отчёта по лабораторной работе №5. Исходный проект `kg5` не изменялся,
поэтому оба варианта можно сравнить напрямую.

## Дефект 1. Определение видимости грани было инвертировано

**Было** (`build_face_records`):

```python
visible = nz < 0
```

Признак вычислялся по z-компоненте нормали в системе координат объекта, тогда
как наблюдатель находится на +Z системы наблюдателя (глубина `z2` из `project()`
растёт при приближении к наблюдателю, так как сортировка «дальние → ближние»
идёт по возрастанию z). В результате программа считала видимыми обратные грани.
Проверка для куба при нулевом повороте:

| | нижняя | передняя | задняя | левая | правая | верхняя |
|---|---|---|---|---|---|---|
| `nz` | −4 | 0 | 0 | 0 | 0 | +4 |
| видима «по программе» (`nz < 0`) | да | нет | нет | нет | нет | нет |
| обращена к наблюдателю | нет | нет | **да** | нет | **да** | **да** |

То есть из шести граней программа показывала только нижнюю (обратную), а три
реально видимые грани не рисовала: тела выглядели вывернутыми наизнанку.

**Исправление.** Все грани строятся сразу в системе координат наблюдателя
(`to_camera`), и грань считается видимой, если её внешняя нормаль направлена к
наблюдателю:

```python
nz = face_normal(pts).z      # pts уже в системе наблюдателя
visible = nz > 0
```

## Дефект 2. Сортировка по z выполнялась в координатах объекта, а не наблюдателя

В `project()` к сцене дополнительно применяется фиксированный наклон камеры
(`yaw = −0.55`, `pitch = 0.35`), поэтому «глубина для наблюдателя» равна
`0,491·x + 0,343·y + 0,801·z`, а не `z`. Сортировка по z-средней в координатах
объекта давала порядок, противоречащий реальному перекрытию: для сцены примера
найдено 6–9 противоречий среди пар граней, перекрывающихся на экране
(расхождение изображений, построенных в двух порядках, достигает 1,8–3,8 %
пикселей).

**Исправление.** Сортировка выполняется по глубине в системе наблюдателя:
вершины граней переводятся функцией `to_camera`, а `z_avg`, `z_min`, `z_max`
вычисляются уже в этой системе. Порядок отрисовки «дальние → ближние»
сохранён (возрастание глубины).

## Дефект 3. Флажок «Подписывать грани» не работал

```python
if self.show_labels:      # объект BooleanVar всегда истинен
```

`tk.BooleanVar` — объект, поэтому условие выполнялось всегда, и подписи граней
рисовались независимо от состояния флажка.

**Исправление:** `if self.show_labels.get():`.

## Дефект 4. Панель «Отображение» не помещалась в окно

При размере окна по умолчанию (1280×800) группа «Отображение» полностью
выходила за пределы окна: измеренная высота рамки 1 px, тогда как для полного
отображения требуется 149 px. Флажки «Показывать скрытые грани», «Подписывать
грани», «Отсечение обратных граней» и ползунок масштаба были недоступны.

**Исправление:** панель управления помещена в прокручиваемую область
(Canvas + Scrollbar + прокрутка колесом), размер окна по умолчанию увеличен до
1280×940.

## Дефект 5. Колонка Zmax таблицы сортировки обрезалась

Суммарная ширина колонок (353 px) вместе с полосой прокрутки превышала ширину
правой панели (340 px), поэтому последняя колонка была частично скрыта.

**Исправление:** ширина правой панели увеличена до 392 px, ширины колонок
скорректированы (38 + 118 + 65 + 65 + 70 = 356 px).

## Дефект 6. Сцена не помещалась на холсте

Проекция совмещает начало мировых координат с центром холста, а фиксированный
масштаб 72 при размере окна 1280×940 выводил часть сцены за левую границу
холста (выход 108 px — обрезалась пирамида).

**Исправление:** добавлен метод `fit_scale()` — подбор масштаба по габаритам
повёрнутой сцены с учётом размеров холста; масштаб подбирается при первом
показе окна и при любом изменении состава сцены, добавлена кнопка
«Вписать сцену».

## Добавленные тесты

В `tests/test_visibility.py` добавлены шесть тестов, фиксирующих исправленное
поведение: соответствие флага видимости знаку нормали, состав видимых граней
куба в исходном положении, ровно три видимые грани куба при произвольных
поворотах, порядок «дальний куб раньше ближнего», совпадение `z_avg` с глубиной
центроида в системе наблюдателя, наличие видимых граней у пирамиды.
Итого в `kg5_fixed` проходит 10 тестов из 10.
