# Лабораторная работа №5 — Видимость многогранников

## Вариант 3

Реализована видимость совокупности произвольных многогранников на основе алгоритма сортировки граней по z-координате.

### Что реализовано

- 3D-сцена с несколькими многогранниками;
- сортировка всех граней по средней z-координате;
- отрисовка граней в порядке «дальние → ближние» (алгоритм художника);
- отображение Zmin, Zср и Zmax каждой грани;
- поворот сцены вокруг X и Y;
- каркас многогранников;
- опциональное отображение скрытых граней;
- опциональное отсечение обратных граней;
- добавление кубов и пирамид;
- удаление объектов;
- сохранение/загрузка произвольной сцены в JSON;
- Docker + Xvfb + x11vnc + noVNC.

## Принцип алгоритма

1. Для каждой грани вычисляются преобразованные 3D-координаты.
2. Для грани определяется средняя z-координата, а также минимум и максимум z.
3. Все грани сортируются по средней z-координате от дальней к ближней.
4. Грани последовательно рисуются на Canvas. Ближняя грань, нарисованная позже, закрывает цвет дальней грани.
5. Таблица справа показывает полученный порядок обработки.

Это соответствует описанному в методических указаниях принципу сортировки поверхностей по глубине и их упорядоченной прорисовки от наиболее глубокой к наиболее близкой.
