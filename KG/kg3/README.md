# Лабораторная работа №3 — поверхность Безье, вариант 3

Приложение строит поверхность Безье для произвольного задающего многогранника и позволяет поворачивать поверхность вокруг осей X и Y.

## Реализовано

- тензорное произведение базисных полиномов Бернштейна;
- произвольная матрица контрольных точек от 2×2 до 8×8;
- редактирование координат X, Y, Z каждой контрольной точки;
- визуализация контрольного многогранника;
- визуализация сетки поверхности Безье;
- поворот вокруг X и Y;
- ортогональное проецирование 3D-сцены на плоскость GUI;
- автоматический масштаб;
- сохранение и загрузка контрольных точек;
- запуск без OpenGL и без сторонних Python-библиотек;
- Docker + Xvfb + x11vnc + noVNC для запуска GUI через браузер.

## Формула

Для контрольного многогранника P[i,j], i=0..m, j=0..n:

S(u,v) = Σ(i=0..m) Σ(j=0..n) B(i,m,u) B(j,n,v) P[i,j]

где

B(i,n,t) = C(n,i) t^i (1-t)^(n-i), 0 ≤ t ≤ 1.

Сначала вычисляется поверхность в исходных координатах, затем каждая точка поворачивается вокруг X и Y, после чего выполняется ортогональная проекция на Canvas.

## Локальный запуск

Нужен Python 3.10+ с Tkinter:

```bash
python app/main.py
```

## Тесты

```bash
python -m unittest discover -s tests -p 'test_*.py'
```

## Docker

Сборка:

```bash
docker build -t bezier-surface-lab3 .
```

Запуск:

```bash
docker run --rm -p 6080:6080 -p 5900:5900 bezier-surface-lab3
```

Открыть в браузере:

```text
http://localhost:6080/vnc.html
```

Для Compose:

```bash
docker compose up --build
```

Затем открыть `http://localhost:6080/vnc.html`.
